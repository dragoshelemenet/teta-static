# teta-static

Static GitHub Pages version of the public teta website.

## What works
- public pages
- blog page
- bilingual EN / DE pages
- static HTML/CSS/JS
- GitHub Pages hosting

## What does not work
- Flask admin
- login
- backend form saving
- image uploads
- testimonial approval
- orders processing

## Deploy
Push to `main`, then in GitHub:
- Settings
- Pages
- Deploy from branch
- Branch: `main`
- Folder: `/ (root)`
